# 偏見プロフィール — TABLE ROOM

顔写真から架空のプロフィールを考え、5人の中から本人を当てる、スマートフォン1台で遊べるパーティーゲームです。

## 遊び方

1. 親以外の書き手だけが人物写真を見て、各自に配られたお題への回答を入力します。
2. 親は匿名・ランダム順の回答を読み、5人の候補からひとりを選びます。
3. 正解した親は、その人物のカード1枚を獲得します。
4. 親が最も「ぽい」と感じた回答を選ぶと、書き手が残りのカード1枚を獲得します。親が不正解でも授与します。
5. カード1枚が1点です。指定した周回数を終えて最多得点の人が勝ち。同点は同点優勝です。

新規対戦は3〜6人、全員が親を1回ずつ担当する1周です。親以外は全員が書き手です。4人以上では各1問、3人では2問と1問を分担します。わかるde賞の受賞者は、場に残った人物カードから1枚を選びます。

## 収録内容と操作

- 独自のお題360個。ジャンル選択なしでランダムに出題します。
- 写真とお題は1ゲーム内で重複しません。次のゲームは未使用カードを優先し、使い切ると再シャッフルします。
- 写真・カード表裏は正方形の表示枠を共有します。写真を引き伸ばしません。
- 生成した専用カード裏面と10種類のプレイヤーアイコンを使用します。
- 入力・進行・配布履歴は端末内に保存します。サーバーへの回答送信やユーザー登録はありません。
- ブラウザを再度開いた場合、書き手の写真は本人確認画面から再開します。
- Web Audioの短い操作音を使用します。ヘッダーで切り替えられます。

## 公開・開発

ビルド不要の静的サイトです。GitHub Pagesで`main`ブランチのルートを公開します。サブディレクトリでの配信に対応しています。モジュールを使用するため、開発時はHTTPサーバーから開いてください。

主な構成：`app.mjs`（画面）、`engine.mjs`（進行・得点）、`topics.mjs`と`extra-topics.mjs`（独自のお題）、`faces.mjs`（人物写真一覧）。描画と配布・得点の処理は分離しています。Service Workerは画面の基本ファイルと閲覧済み画像を保存します。未閲覧の写真には通信が必要です。

## クレジット

ルール参考：[ゲーム工房カコムタク「偏見プロフィール」](https://gamemarket.jp/game/182183)。対決ルールをもとにした個人制作のWebアレンジで、公式商品ではありません。お題文と人物画像はこのWeb版のために独自制作しています。

登場する人物は画像生成AIで作成した架空の成人です。入力されたプロフィールもゲーム上の創作であり、実在人物の事実や属性を示しません。

日本語書体：Zen Kaku Gothic New（Google Fonts配信）。外部書体が利用できない場合は端末の日本語書体で表示します。
